# Gloop — Pre-Alpha Vertical Slice

> **PRE-ALPHA VERTICAL SLICE / PROOF OF CONCEPT**  
> This is an unfinished systems demonstration, not a finished game.

Gloop is a living-alchemy tactical puzzle prototype about a strange organism that absorbs matter,
changes Temper, splits, recombines, and helps a vulnerable Hero cross dangerous Origins.

## Download

The playable archives are available directly from this repository's `main` branch and from the
[Releases page](https://github.com/Illiterally/Gloop-Vertical-Slice/releases).

- **[Download Windows 64-bit](./Gloop-PreAlpha-Vertical-Slice-Windows-x64.zip?raw=1)**
- **[Download macOS Universal](./Gloop-PreAlpha-Vertical-Slice-macOS-Universal.zip?raw=1)**

- **Windows 64-bit:** unzip the complete archive, open `Gloop-Windows`, and run `Gloop.exe`.
- **macOS Universal (Apple silicon + Intel):** unzip, then open `Gloop.app`. The app is not yet
  notarized. If macOS blocks the first launch, Control-click the app, choose **Open**, then confirm
  **Open** once.

## What is in this slice

- A small summer Overworld connecting the game's modes.
- Twelve linked tactical Origins that introduce movement, mass, layers, and elemental Tempers.
- The completed Air Temper finale, **Origin: Wind Roads**, built around Thermal Vents, Bounce, and
  Balloon currents.
- A physical Tablework bench and evidence-driven Fieldbook foundation.
- Mouse and keyboard camera controls, fullscreen support, and authored tactical HUDs.

## Pre-alpha boundaries

- Campaign disk saves are not implemented; **Continue** is intentionally disabled.
- The Level Forge is currently a Unity Editor development tool, not a feature in this player build.
- The experimental Free Create / parcel sculptor is not included in the public route.
- Art, writing, balance, onboarding, performance, and compatibility are all in active development.
- Expect bugs, rough edges, placeholder assets, and systems that may change substantially.

## Basic controls

- **Overworld movement:** `WASD` or arrow keys
- **Confirm / enter an Origin:** `Enter`, `Space`, or the on-screen button
- **Orbit camera:** right-drag
- **Pan camera:** middle-drag
- **Zoom:** mouse wheel
- **Frame the play area:** `F`
- **Fullscreen:** `F11`

Please report problems through [GitHub Issues](https://github.com/Illiterally/Gloop-Vertical-Slice/issues)
and include your operating system plus a screenshot when possible.
