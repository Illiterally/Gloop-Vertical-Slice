# Gloop Pre-Alpha Vertical Slice v0.1.0

> **PRE-ALPHA VERTICAL SLICE / PROOF OF CONCEPT**  
> This build is unfinished, unbalanced, and intended to demonstrate the game's core direction.

## Included

- Windows 64-bit player build.
- Universal macOS player build for Apple silicon and Intel.
- A small summer Overworld and a linked twelve-Origin tactical campaign.
- The completed Air Temper finale, **Origin: Wind Roads**, featuring Thermal Vents, Bounce, and
  Balloon currents.
- The current Tablework bench and Fieldbook foundation.

## Deliberate boundaries

- Continue is disabled because campaign disk saves are not implemented.
- Free Create has been removed from the public route.
- Level Forge remains an internal Unity Editor authoring tool.
- The macOS app is not notarized; see the archive read-me for first-launch instructions.
